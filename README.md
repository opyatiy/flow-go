# Flow Go

Нативный загрузчик для **PSP Go с ARK-4**: интерфейс в духе XMB, отдельный
каталог homebrew, очередь, обложки, фоновая музыка и технический раздел.

Native PSP Go downloader and homebrew browser for ARK-4. Russian UI and documentation.
**Experimental: physical-device networking and installation still need validation.**

**Версия 0.7.3 — тестовая.** Пользователь подтвердил запуск приложения и загрузку
каталога на PSP Go 05g / 6.60 ARK-4 cIPL в ходе разработки. Новые исправления
0.7.3 прошли проверки на ПК, но ещё не подтверждены на самой PSP.

## Возможности

- Разделы **PSP → Homebrew → Избранное → Загрузки → Настройки → О PSP**.
- Онлайн-каталоги с отдельным кэшем на накопителе, обновление через START.
- Homebrew из [PSPDEV Homebrew Database](https://github.com/pspdev/homebrew).
- Собственные HTTP/HTTPS-источники через текстовый файл в корне памяти.
- Очередь, пауза и удаление задач; скорость, объём, время и проверка SHA-256.
- ISO/CSO, PBP, поддерживаемые PSP PKG и ZIP homebrew.
- Проверка путей ZIP и CRC, запрет перезаписи установленных приложений.
- Обои PNG, затемнение, цветные значки кнопок, встроенный японский шрифт.
- Фоновый WAV и реальные ответы системных API в техническом разделе.

## Установка

Скачай архив из [Releases](https://github.com/opyatiy/flow-go/releases).
Закрой Flow, подключи PSP к компьютеру и скопируй папку **PSP** в корень памяти
с объединением папок. Запускай через меню игр PSP:

```text
PSP/GAME/FLOWGO/EBOOT.PBP
```

**Старую папку FLOWGO целиком не удаляй.** Настройки, очередь, избранное и кэш
сохраняются. `EBOOT.PBP` — исполняемый пакет PSP, содержащий программу и метаданные.
Для HTTPS рядом нужен `cacert.pem`, для музыки — `music.wav`.
Японский шрифт встроен в EBOOT. Публичная поставка не содержит игр или готовых
обложек коммерческих игр.

Цель — **PSP Go / ARK-4**. Программа импортирует функции ARK; официальная прошивка
и другие CFW не заявлены как совместимые. Wi-Fi сначала настрой и проверь в XMB.

## Управление

| Кнопка | Действие |
|---|---|
| L / R | Переключить раздел |
| Влево / вправо | Соседняя игра |
| Вверх / вниз в каталоге | Перейти на 10 игр |
| Вверх / вниз в очереди и настройках | Выбрать строку |
| Вверх / вниз в «О PSP» | Страница диагностики |
| Крест в каталоге | Подтверждение; повторный крест — в очередь |
| Крест в очереди | Пауза / возобновление / повтор после ошибки |
| Квадрат в каталоге | Избранное |
| Квадрат в очереди | Удалить задачу и временный файл |
| Треугольник в каталоге | Запросить обложку |
| SELECT | Поиск |
| START | Обновить текущий каталог |

В поиске: крест — символ, квадрат — стереть, треугольник — страница клавиатуры,
L — пробел, START — применить, круг — отмена.
Избранное относится к текущему загруженному каталогу.
Удаление завершённой задачи не удаляет установленную игру.

## Свои источники — с компьютера

После первого запуска в корне накопителя приложения появится **flow-sources.txt**,
рядом с PSP и ISO. Существующий файл не перезаписывается. Сохраняй UTF-8:

```text
Мой каталог | https://example.org/catalog.tsv
Домашний сервер | http://192.168.1.10:8080/catalog.tsv
```

Это примеры, а не действующие адреса. После редактирования перезапусти Flow
и выбери **Настройки → Источник PSP**. Homebrew открывается отдельной вкладкой.
До 10 собственных источников; строки с `#` — комментарии.
Старый `sources.tsv` переносится при первом создании корневого файла.
Нужен прямой URL списка, а не веб-страница или папка.

[Пример файла](examples/flow-sources.example.txt) · [Формат каталога](docs/CATALOGS.md)

## Обои и музыка

PNG положи в `PSP/GAME/FLOWGO/wallpapers/` и выбери в настройках.
Экран — 480×272; затемнение работает и со встроенным фоном.
`music.wav` — PCM16 stereo, 44100 Hz, канонический 44-байтовый заголовок WAV.
Свой фоновый цикл можно сгенерировать: `python make_music.py`.

## Ограничения

- **HTTPS после паузы скачивается заново.** HTTP-докачка поддерживается.
- Остановка системного сетевого вызова может ждать его таймаута.
- Обложки обслуживаются после очереди игр, их наличие не гарантируется.
- Внешние серверы могут быть недоступны; при проверках встречался HTTP 504.
- FTP/SFTP, авторизация логином/паролем, IPv6 и RAR/7z не реализованы.
- ZIP: до 8192 элементов и 1 ГиБ после распаковки; один корень приложения.
  Вложенные EBOOT разрешены; несколько отдельных приложений в одном ZIP — нет.
- Максимальный файл — 2147483647 байт. Перезапись существующей установки запрещена.
- `[DATA]` у homebrew означает необходимость дополнительных файлов от пользователя.
- CPU 333 / BUS 166 МГц в сеансе Flow могут увеличивать расход батареи.
- Температура, напряжение и ёмкость зависят от Power API. Достоверный износ
  не определяется; отсутствующие значения не подменяются догадками.
- Наличие homebrew в каталоге не гарантирует совместимости с PSP Go.

## Ошибки и проверка

Создай [issue](https://github.com/opyatiy/flow-go/issues/new/choose): версия Flow,
модель/CFW, название homebrew, точный статус, этап операции и `flow.log`.
Лог лежит в `PSP/GAME/FLOWGO/`. Перед публикацией убери личные названия Wi-Fi,
адреса локальной сети и другие приватные данные. Не прикладывай настройки или токены.

[Что проверено и как диагностировать](docs/TESTING.md) · [Изменения](CHANGELOG.md)

## Разработка

[Сборка](docs/BUILD.md): Python 3, Pillow, numpy и PSPDEV.
Основная команда — `python build.py` при установленном `PSPDEV`.

- `ui.c`, `ui_extras.inc` — framebuffer-интерфейс, текст и диагностика.
- `sources.c`, `catalog.c`, `homebrew.c` — источники и парсеры.
- `network.c`, `tls_fetch.c`, `wifi_connect.inc` — HTTP/TLS/Wi-Fi.
- `scheduler.c`, `performance.c` — очередь и уступка CPU.
- `install.c`, `install_zip.c` — установка; `music.c` — аудио.
- `tests/`, `tools/` — проверки.

# Участие

Для ошибки используй issue template и укажи точную версию/CFW/этап операции.
Приватные сведения из логов удаляй перед публикацией.

Для изменения кода приложи описание проблемы, новое поведение и проверки.
Не смешивай косметические изменения с сетевыми/установочными исправлениями.
Не ослабляй проверку сертификатов, SHA-256, путей ZIP или запрет перезаписи.

Быстрый host-тест очереди и источников:

```sh
python tests/run_queue.py
```

Нужен C-компилятор. Например: `python tests/run_queue.py --cc zig cc`.
CI запускает этот тест; он не проверяет PSP TLS, GUI или скорость устройства.
Для изменений платформенного кода нужна сборка PSPDEV и, по возможности,
тест на PSP Go с явно указанными результатами. Не выдавай host-тест за device-тест.

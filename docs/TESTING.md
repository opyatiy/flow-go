# Статус и диагностика

## Что известно

Во время разработки пользователь запускал Flow на PSP Go 05g / 6.60 ARK-4 cIPL.
После исправлений TLS/RTC каталог стал загружаться. Позже сообщались низкая
скорость, неотзывчивость, зависание очереди, отсутствие обложек и проблемы homebrew.

В 0.7.3 исправлены найденные в коде причины, но **физическое устройство ещё не
подтвердило результат этой версии**. Нельзя утверждать, что все сетевые сбои устранены.

На ПК проверены:

- сборка EBOOT, явный резерв heap 8192 КиБ, встроенный шрифт;
- отсутствие старых дублирующихся TLS objects, использование RTC для X.509;
- 1593 подходящих записи из использованного снимка PSPDEV;
- Unicode и сохранение/чтение кэша;
- источник из корневого файла, переключение вкладок, пауза/возобновление;
- удаление соседней задачи при активной, отложенное удаление активной;
- обычный/вложенный ZIP, запрет traversal, дубликатов, нескольких приложений;
- реальная загрузка TileFinch на ПК, размер/SHA-256 и распаковка двух EBOOT.

Эмулятор не использовался. Скорость на PSP после оптимизаций не измерена.
Проверка отдельного сервера с ПК не доказывает его работоспособность с PSP.

## Если «В очереди» или «Загрузка» не меняется

Укажи точную версию, название приложения и нижнюю строку экрана очереди.
Крест запрашивает паузу; квадрат — остановку и удаление.
Системный сетевой вызов может завершиться лишь по таймауту.
Проверь тот же Wi-Fi профиль в XMB. Сохрани `flow.log` до следующего теста.

В логе важны `Network worker`, `Queue start`, `HTTPS stage`, `HTTPS status`,
`Queue finish`, ошибки APCTL и состояние часов. Не публикуй токены, приватные URL,
названия Wi-Fi или локальные адреса, если не хочешь раскрывать их.

HTTPS-докачка пока отсутствует: повтор после паузы начинает файл заново.
HTTP 404/403/504 — ответы источника; переустановка приложения не гарантирует исправления.

## Обложки и аккумулятор

Обложки получают сеть после очереди игр. Для PSP нужен свой `covers.tsv`
или локальный PNG; для homebrew таблица создаётся при обновлении базы.

Отрицательный код Power API означает отсутствие доступного значения, а не
отрицательное напряжение/температуру. Надёжного измерения износа в Flow нет.

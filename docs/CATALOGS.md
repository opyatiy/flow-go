# Каталоги и файлы

## Список источников

`/flow-sources.txt` читается с накопителя приложения: `ef0:` или `ms0:`.
UTF-8, BOM допустим, до 10 записей `Название | URL`. Пустые строки и комментарии
с `#` пропускаются. После изменения перезапусти приложение.
HTTP/HTTPS поддерживаются; источник должен возвращать сам файл каталога.

## TSV

UTF-8 с настоящими табуляциями, до 6000 записей и 4 МиБ. Поля строго по порядку:

| Поле | Значение |
|---|---|
| id | До 40 ASCII букв/цифр, `_` или `-`; уникальный между источниками |
| name | Название, до 191 байта UTF-8 |
| region | До 15 байт UTF-8 |
| kind | `iso`, `cso`, `pbp`, `pkg`, `zip` |
| size | Размер скачиваемого файла в байтах; 0 — неизвестен; максимум 2147483647 |
| sha256 | 64 шестнадцатеричных символа; пустое поле отключает эту проверку |
| url | Прямая HTTP/HTTPS ссылка, до 1023 байт |

Первая строка: `id`, `name`, `region`, `kind`, `size`, `sha256`, `url`, разделённые TAB.
Внутри полей TAB и переводы строк запрещены. SHA-256 рекомендуется указывать.
Поддерживаются также JSON PSPDEV и исходный TSV PSP Games.
Исходный код содержит адрес внешнего источника PSP Games; его доступность
и содержимое не контролируются этим проектом. Игровые файлы здесь не размещаются.

## Кэш

Основной источник: `catalog.tsv`; остальные: `catalog-<URL hash>.tsv`.
Обновление проверяется до замены кэша, прерванная замена может восстановиться из `.bak`.
При работе список находится в RAM; постоянный кэш — на накопителе.
Скачиваемые игры пишутся потоково, не помещаются целиком в RAM.

## Установка

ISO/CSO устанавливаются в `ISO`, PBP и ZIP — в `PSP/GAME/<id>`.
PKG поддерживается для реализованного преобразования PSP NPUMDIMG; другие виды
пакетов не заявлены. ZIP распаковывает дерево основного EBOOT, включая вложенные
EBOOT этого приложения. Несколько независимых корней, traversal, дубликаты,
шифрование и симлинки отклоняются. Перезапись существующей игры запрещена.

## Обложки

Локальный PNG: `PSP/GAME/FLOWGO/covers/<id>.png`.
Для обычного каталога можно создать `covers.tsv` рядом с EBOOT:
одна строка `id<TAB>прямой URL PNG`. Автоматического поиска по названию нет.
Homebrew создаёт `homebrew-covers.tsv` при загрузке JSON PSPDEV.
Отсутствие карты, записи или PNG не блокирует установку игры.
Публичный архив не содержит изображений коммерческих игр.
